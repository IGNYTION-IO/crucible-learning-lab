# Crucible Learning Lab

A collection of open silicon-design experiments and learning resources for students, educators, and engineers using **Crucible by Ignytion IO**.

## Experiment Repositories

| Domain          | Repository                                                                                     | Description                                                                                                                          |
| --------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Digital Design  | [digital-design](https://github.com/CRUCIBLE-WORKBENCH/digital-design)                         | Digital logic, RTL design, simulation, and verification experiments                                                                   |
| Analog Design   | [analog-design](https://github.com/CRUCIBLE-WORKBENCH/analog-design)                           | Analog circuit design and simulation experiments                                                                                      |
| Physical Design | [apb-rtl-to-gds-sky130](https://github.com/CRUCIBLE-WORKBENCH/apb-rtl-to-gds-sky130)           | RTL-to-GDS flow for an AMBA APB design (master + 2 slaves) on the open SKY130 PDK, orchestrated end-to-end with `make` and `igny`     |
| FPGA Design     | Coming soon                                                                                    | FPGA implementation and prototyping experiments                                                                                      |
| RISC-V and SoC  | Coming soon                                                                                    | Processor, peripheral, and system-on-chip experiments                                                                                 |

Additional experiment repositories will be added as they become available.
